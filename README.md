# Mansors — облегчённая демонстрационная версия

Загрузите содержимое папки в корень существующего репозитория, заменив одноимённые файлы. Сохраните существующую настройку GitHub Actions для Pages. Первый экран использует фотографию и параллакс при прокрутке. Заставка подготавливает изображения страницы; при медленном соединении ожидание ограничено.
