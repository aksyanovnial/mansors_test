# Mansors Dubai — готовая статическая сборка

Загрузите содержимое этой папки в корень GitHub-репозитория. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), затем Save. Страницы могут появиться не сразу.

Папка assets содержит собранные шрифты, изображения и скрипты; team — фотографии команды. Файлы с точкой в начале имени тоже полезно загрузить. Это готовый сайт, а не исходный Astro-проект. Формы заявки и подписки в прототипе не отправляют данные.
