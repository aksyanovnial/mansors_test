# Mansors — облегчённая демонстрационная версия

Загрузите содержимое папки в корень существующего репозитория, заменив одноимённые файлы. GitHub Pages: ветка main, папка / (root). Первый экран упрощён для демонстрации дизайна: цельная фотография и параллакс при прокрутке; без свечений, прожекторов, процедурной дымки и движения отдельных зданий. Заставка ждёт изображение первого экрана и шрифт.
